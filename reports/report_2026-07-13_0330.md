# Incident Report

## Summary
A ransomware incident was detected on May 2, 2026, where an attacker gained access to the system through a brute-force login attempt and subsequently encrypted files. The attacker used a shared IP address (185.220.101.47) across multiple logs.

## Timeline

* 01:14:07 - Failed login attempt from 185.220.101.47
* 01:20:55 - Successful login from 185.220.101.47
* 01:22:03 - File creation on \\fileserver\share\invoice.docx
* 01:31:40-42 - Mass file renames and locked files created

## Root Cause
The attacker gained access through a brute-force login attempt, and then used the shared IP address (185.220.101.47) to establish further communication with the system.
